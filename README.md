# جواب خاص

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى المستودع، مع الحفاظ على أسماء الملفات كما هي.
2. من المستودع افتح **Settings → Pages**.
3. تحت **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
5. بعد اكتمال النشر، افتح الرابط الظاهر في إعدادات Pages.

يجب أن يبقى `index.html` في جذر المستودع، وأن ترفع معه كل ملفات الصور والخط والصوت المستخدمة في الموقع.
