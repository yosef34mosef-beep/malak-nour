# جواب خاص

## النشر على GitHub Pages

1. ارفعي الملفات المطلوبة الموضحة أدناه إلى جذر المستودع.
2. افتحي **Settings → Pages** في المستودع.
3. من **Build and deployment** اختاري **Deploy from a branch**.
4. اختاري الفرع `main` والمجلد `/(root)` ثم اضغطي **Save**.
5. بعد اكتمال النشر، افتحي الرابط الذي يظهر في إعدادات Pages.

لا يحتاج الموقع إلى أدوات بناء أو تثبيت حزم؛ ملف `index.html` جاهز للنشر مباشرة. ملف `.nojekyll` موجود لتجنب معالجة Jekyll.

### الملفات المطلوبة للنشر

- `index.html`
- `backgraond.jpg`
- `the heart.png`
- `left_card.png`
- `right_card.png`
- `ks_hand.ttf`
- `music.mp3`
- `.nojekyll`

الصور التسع وغلاف الأغنية والفيديو تُحمّل من Google Drive، لذلك تأكدي من ضبط مشاركة كل ملف على **أي شخص لديه الرابط**. لا ترفعي صور `1.jpg` إلى `9.jpg`؛ المعرض يستخدم روابط Drive.

### الفيديو

GitHub Pages لا يحوّل صيغة الفيديو. ملف الفيديو الحالي على Drive يستخدم ترميز AV1، وقد لا يعمل في بعض المتصفحات. لضمان التشغيل، ارفعي نسخة MP4 بترميز H.264 إلى Drive مع إتاحة الرابط، ثم حدّثي رابط الفيديو في `index.html`.

### المعاينة على Windows

لتجربة الموقع محليًا، افتحي `تشغيل الموقع محليًا.bat` بدل فتح `index.html` مباشرة؛ بعض المتصفحات تمنع تشغيل الصوت عند فتح الصفحة بعنوان `file://`. هذه الأداة وملف `serve-local.ps1` للمعاينة المحلية فقط، وليسا مطلوبين للنشر.
